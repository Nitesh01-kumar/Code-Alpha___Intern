# C++ Internship Projects

This repository contains multiple C++ console-based applications developed as internship tasks.
The projects focus on problem-solving, object-oriented programming, recursion, file handling, and data management concepts using C++.

## Projects Included

### 1. CGPA Calculator System

A student CGPA calculator that allows users to:

* Enter course details
* Calculate GPA/CGPA
* Display semester reports
* Evaluate performance
* Find best and weakest courses
* Search course information

### 2. Login and Registration System

A file-handling based authentication system featuring:

* User registration
* Secure login
* Duplicate username checking
* Password validation
* Forgot password functionality
* Account deletion and password update

### 3. Sudoku Solver

A Sudoku puzzle solver implemented using recursion and backtracking:

* 9x9 Sudoku board
* Validity checking
* Recursive solving algorithm
* User puzzle input
* Formatted board display

### 4. Banking Management System

A banking system developed using object-oriented programming concepts:

* Customer account management
* Deposit and withdrawal system
* Fund transfer
* Transaction history
* Balance inquiry
* Multiple customer handling

## Technologies Used

* C++

These projects were developed as part of an internship program to improve practical programming skills, logical thinking, and software development fundamentals using C++.
